# Print a batched multi-response occu_cover fit.

Print a batched multi-response occu_cover fit.

## Usage

``` r
# S3 method for class 'tobs_batch'
print(x, ...)
```

## Arguments

- x:

  A `tobs_batch` returned by
  [`tobs()`](https://gillescolling.com/tulpaObs/reference/tobs.md) on
  multi-response `y`.

- ...:

  Ignored.

## Value

`x`, invisibly.
