visit completeness, and spatial detection map (if coordinates
available).

## Usage

``` r
# S3 method for class 'tobs_data'
plot(x, ...)
```

## Arguments

- x:

  An `tobs_data` object.

- ...:

  Ignored.

## Value

Invisible `NULL`.
